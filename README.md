# TaskFlow – Student Task Management System

## Team Members

- Aradhya Sharma – Team Leader & UI Integration
- Aaryan – Frontend Functionality
- Gunit – Backend Development

## Features

- Add Task
- Edit Task
- Delete Task
- Mark Task as Complete
- Search Tasks
- Filter Tasks
- Task Statistics

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run

1. Clone the repository.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.
